- The repository has no V5 generator yet. This fixture therefore does not prove what a future vendomat sync does with VENDOMAT_SOURCE_ROOT.

## Inference

A git+file lock entry requires a Git source at its recorded absolute URL. Moving only the consumer checkout does not break it. Moving or omitting the source does.

A local override can select a source at another path. It does not rewrite the lock when Nix runs with --no-write-lock-file. A later Nix lock operation must record the new URL.

The public cache did not provide the missing local Git source. This fixture did not access the private Attic cache. PV-09 covers that route.

## Decision

Keep the generic relocation claim failed. The current design can use one fixed /home/andrew/vendor path on every host, but each clone must exist before Nix evaluates the consumer.

Treat VENDOMAT_SOURCE_ROOT as a generator input. A changed root must change the generated flake URL, then Nix must update flake.lock. PV-03 did not test that future generator behavior.

Keep STORE-001 and STORE-004 open until a generator fixture proves the override and a restore fixture proves clone recovery. Assign a new ID if either requirement changes.
