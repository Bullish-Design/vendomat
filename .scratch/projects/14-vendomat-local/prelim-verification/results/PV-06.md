## Inference

The option type, not the TOML value's shape alone, determines whether a string list contains packages or strings. Resolving every all-string list corrupts group lists. Package conversion needs an explicit set of package-valued option paths. Unknown package names must fail with the option path and name.

Nix's native type merge allows equal scalar values, rejects unequal scalar values, and concatenates list values. The blanket claim that every definition in both TOML and Nix must fail is false for these options. The fixture used the common wrapper only to continue evaluating the converter's value behavior; it does not repair the documented converter implementation.

## Decision

Revise the converter to return a valid module, limit package resolution to declared package-valued options, and leave ordinary lists intact. Use native Nix option merging as the default conflict policy. If strict cross-file duplicate rejection remains a requirement, define and test it separately. Preserve `SYS-001` to `SYS-007`; PV-12 must assign new IDs to any changed requirements.
