## Inference

The inline module filter supports a module-bearing input, a flake without that module, and a non-flake input. The option remains inactive until enabled, and the standalone package and impure shell do not depend on Vendomat.

The proposed default shell command does not work with the pinned devenv and ordinary pure evaluation. `--impure` supplies the current directory and makes the shell work, but that flag is absent from the guide's acceptance command. The fixture did not test an empty store or a future `vendomat sync` output.

## Decision

Revise the generated shell contract and its guide commands before claiming `GEN-009` or `DEL-005`. Define how a pure `nix develop` obtains a writable consumer root, or explicitly adopt and verify an impure shell command. Keep `GEN-004`, `GEN-010`, `GEN-011`, and `GEN-012` as feasible in this static fixture. Do not treat this as the later generator acceptance test.

## Follow-up

Resolve the consumer-root interface, then rerun the default shell command and a cold-store consumer fixture.
