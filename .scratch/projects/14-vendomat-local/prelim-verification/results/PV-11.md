## Inference

The fixture supports a Nix-only shared core that boots without Vendomat Python. Putting the CLI package in `environment.systemPackages` makes its evaluation and build part of the host system. The current `.default` example installs a wheelhouse, not the CLI. This VM does not prove the production server's network, cache access, or boot.

## Decision

Supersede DEL-001 with a new requirement that keeps the shared boot core independent of the CLI and adds the CLI only in an explicit later host delta. Add a separate requirement for the correct CLI package output attribute, `.vendomat`. Update the guide to use that attribute and move it out of the core. Keep BOOT-001, BOOT-006, and BOOT-009 limited to this disposable VM fixture until real-machine acceptance.
