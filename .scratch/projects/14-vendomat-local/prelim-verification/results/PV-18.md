## Observations

- **Run 1 failed, and the failure mattered.** After a tag push over SSH, a push of `main` to the server also succeeded. Git refuses only a push to the *checked-out* branch, and the server repository's HEAD was `master`. "Only release tags enter" therefore needs a server-side hook. Run 2 added a `pre-receive` hook; its last check failed on shell quoting in the test only. Run 3 passed.
- Run 3: the tag push was accepted. The branch push was refused: `collection: only release tags are accepted, not refs/heads/main`. A force push of a moved tag was refused: `collection: refs/tags/v1.0.0 exists; releases are immutable`. A new tag was accepted. The repository ended with `v1.0.0` and `v1.0.1` and no branch.
- Before the export marker existed, `git ls-remote git://server/lib-a` failed. After `touch .git/git-daemon-export-ok` it listed the tags. A second repository without the marker was not served. A push over `git://` failed.
